# 全网优质 AI 学习路线（新手权威版）

> 这一页是我从全网筛选出的**权威、适合新手**的 AI 学习资源。它和 [我的进阶路线](/roadmap) 是互补关系：那边是我的个人学习地图，这边是"站在巨人肩膀上"的外部权威课程与路线图。
>
> 筛选标准只有三条：**来源权威**（名校 / 一线公司 / 领域大牛）、**适合零基础或转行新手**、**知识过硬**（不是蹭热度的快餐课）。所有标注"免费"的资源都无需付费即可学到核心内容（证书可要可不要）。

## 怎么用这一页

- 按"层级"从下往上爬：先概念启蒙，再打基础，最后深入原理与工程落地。
- 每个资源都标了**适合人群 / 语言 / 是否免费**，按需取用，不必全学。
- 别被"课多"吓到——**挑 1 条主线走完，比囤 10 门课更有用**。

## 一、零基础 / 非技术：先搞懂"AI 是什么"

这一层不需要写一行代码、不碰数学，目标是建立正确的 AI 世界观，避免被营销话术带偏。

::: tip Elements of AI（赫尔辛基大学 + MinnaLearn）
- **权威度**：⭐⭐⭐⭐⭐　**语言**：多语言（含中文）　**免费**：100% 免费 + 免费证书
- **适合**：完全零基础、怕被术语劝退的人；也适合管理者/业务岗。
- **亮点**：由芬兰赫尔辛基大学发起的国民级科普项目，全球 200 万+ 学员，谷歌 CEO 公开点赞。没有公式、没有代码，把"AI 能做什么、不能做什么、怎么造出来"讲透。
- **链接**：[elementsofai.com](https://www.elementsofai.com/)
:::

::: tip Google AI Essentials（Google 官方，Coursera）
- **权威度**：⭐⭐⭐⭐⭐　**语言**：英文（可字幕）　**免费**：可免费旁听
- **适合**：职场人、想立刻把 AI 用在日常工作的。
- **亮点**：Google 专家出品，不到 10 小时，交互式练习 + 真实场景（Gemini、提示词、负责任使用），"即学即用"感最强。
- **链接**：[Coursera](https://www.coursera.org/learn/google-ai-essentials)
:::

::: info AI for Everyone（Andrew Ng / DeepLearning.AI）
- **权威度**：⭐⭐⭐⭐⭐　**语言**：英文　**免费**：可免费旁听（250 万+ 学员）
- **适合**：想从"战略/商业影响"角度理解 AI 的人（管理者、产品、运营）。
- **亮点**：吴恩达（Google Brain 联合创始人、AI 教育界最受尊敬的人之一）主讲，约 6 小时，零代码零数学，讲清 AI 项目怎么跑、坑在哪。
- **链接**：[deeplearning.ai](https://www.deeplearning.ai/courses/ai-for-everyone/)
:::

::: info Microsoft AI for Beginners（GitHub 开源）
- **权威度**：⭐⭐⭐⭐　**语言**：英文　**免费**：100% 开源免费
- **适合**：喜欢"有结构、有实验"的系统型学习者。
- **亮点**：微软出品，24+ 小时，含 TensorFlow 实验和**实打实的伦理模块**（不是两句话带过），配套徽章。
- **链接**：[github.com/microsoft/AI-For-Beginners](https://github.com/microsoft/AI-For-Beginners)
:::

## 二、中文友好启蒙（母语学习，少走弯路）

如果你更习惯中文讲解，下面三个是华语社区公认的"最好入门"资源。

::: tip 李宏毅《机器学习》2025（台湾大学）
- **权威度**：⭐⭐⭐⭐⭐　**语言**：中文　**免费**：B 站 / YouTube 全免费
- **适合**：中文母语、想系统入门深度学习的任何人；先修只需 Python。
- **亮点**：台大李宏毅教授，华语 AI 教学第一人，用"宝可梦"等生动例子讲透复杂概念。2025 版全面转向大模型时代——RAG、AI Agent、LLM 内部机制、DeepSeek-R1 怎么"深度思考"，紧跟前沿。约 80 小时。
- **链接**：[课程主页](https://speech.ee.ntu.edu.tw/~hylee/ml/2025-spring.php) · [YouTube 频道](https://www.youtube.com/@HungyiLeeNTU)
:::

::: tip 李沐《动手学深度学习》（Dive into Deep Learning, D2L）
- **权威度**：⭐⭐⭐⭐⭐　**语言**：中文　**免费**：官网全免费
- **适合**：自学者、工程实践型学习者（有 Python 基础）。
- **亮点**：李沐（前 AWS 首席科学家）等合著，被公认为"目前最好的深度学习入门书，没有之一"。每一节都是**可运行的 Jupyter 笔记本**（公式 + 图示 + 代码三合一），改代码、调超参即时反馈。官网 [zh.d2l.ai](https://zh.d2l.ai/) 配套 B 站教学视频。
:::

::: tip 3Blue1Brown 神经网络系列
- **权威度**：⭐⭐⭐⭐⭐　**语言**：英文（B 站有中配）　**免费**：YouTube / B 站
- **适合**：所有想建立"几何直觉"的人，建议配合任何课程先看。
- **亮点**：用精美动画把神经网络运算讲成"看得见的几何变换"，约 1 小时，公式极少。看它 + 李沐，一个讲直觉、一个讲实操，绝配。
- **链接**：[YouTube @3blue1brown](https://www.youtube.com/@3blue1brown)
:::

## 三、打基础：机器学习 / 深度学习入门（需 Python）

这一层开始动手写代码，目标是真正"跑通一个模型"，而不是只听懂概念。

::: tip Andrew Ng 机器学习专项课程（DeepLearning.AI + 斯坦福）
- **权威度**：⭐⭐⭐⭐⭐　**语言**：英文　**免费**：可免费旁听
- **适合**：想扎实打基础的新手（无需重数学背景，数学放进"可选视频"）。
- **亮点**：吴恩达与斯坦福联合重制版（原版被几代学习者当作 ML 职业入口），三课程、95 小时、151 节课，先直观视觉讲解、再逐步代码实现。公认的 ML 入门"正路"。
- **链接**：[deeplearning.ai](https://www.deeplearning.ai/specializations/machine-learning)
:::

::: tip fast.ai《Practical Deep Learning for Coders》
- **权威度**：⭐⭐⭐⭐　**语言**：英文　**免费**：100% 免费
- **适合**："先跑通再问为什么"的动手派、有编程经验的人。
- **亮点**：自上而下、代码优先——先让你把模型跑起来，再回头讲原理。不注水，但也不简单，适合想真做项目的人。
- **链接**：[course.fast.ai](https://course.fast.ai/)
:::

::: tip Hugging Face 系列课程（huggingface.co/learn）
- **权威度**：⭐⭐⭐⭐⭐　**语言**：英文（大量中文社区搬运）　**免费**：100% 免费
- **适合**：想直接上手 NLP / LLM / Agent / 强化学习的实战派。
- **亮点**：用 HF 自家技术栈（Transformers 等）的官方实战课，非常动手，紧跟大模型应用前沿。
:::

::: info CS229（斯坦福，Andrew Ng）
- **权威度**：⭐⭐⭐⭐⭐　**语言**：英文　**免费**：公开课
- **适合**：数学底子好、想深究理论的人（新手慎入，数学较重）。
- **链接**：[cs229.stanford.edu](https://cs229.stanford.edu/)
:::

## 四、深入原理：搞懂大模型"内部怎么转"

当你能跑通模型后，这一层帮你"看穿"Transformer 和 LLM 的本质——也是本博客 [基础模型](/base-models/claude) / [模型架构](/architecture/) 等笔记的理论根基。

::: tip Andrej Karpathy《Neural Networks: Zero to Hero》
- **权威度**：⭐⭐⭐⭐⭐　**语言**：英文（B 站有中配）　**免费**：YouTube
- **适合**：有基础 Python、想真正理解神经网络的人。
- **亮点**：前特斯拉 AI 负责人 Karpathy 免费课，**从零手写一个 GPT**，逐行实现。15-20 小时，被多家学习指南列为"深度理解首选"。
- **链接**：[karpathy.ai/zero-to-hero](https://karpathy.ai/zero-to-hero.html)
:::

::: tip Sebastian Raschka《Build a Large Language Model From Scratch》(2024)
- **权威度**：⭐⭐⭐⭐⭐　**语言**：英文　**免费**：代码开源（书付费）
- **适合**：想亲手实现完整 LLM、打通"论文→代码"的人。
- **亮点**：Raschka 是权威 AI 教材作者，这本书被奉为"从论文到代码的桥梁"，GitHub 上有完整可运行代码。
- **链接**：[Manning 出版社](https://www.manning.com/books/build-a-large-language-model-from-scratch)
:::

::: info Stanford CS224N（深度学习自然语言处理）
- **权威度**：⭐⭐⭐⭐⭐　**语言**：英文　**免费**：YouTube 公开课
- **亮点**：NLP 与 LLM 的"学术基石"，想走研究/算法岗必看。
- **链接**：[web.stanford.edu/class/cs224n](https://web.stanford.edu/class/cs224n/)
:::

::: info Stanford CS336（Language Modeling from Scratch）
- **权威度**：⭐⭐⭐⭐⭐　**语言**：英文　**免费**：公开课
- **亮点**：从零搭建一整套 LLM 训练栈，最接近前沿实验室真实做法的研究级课程。
- **链接**：[stanford-cs336.github.io](https://stanford-cs336.github.io/)

学完原理，这一层教你"怎么把模型变成能用的产品"——也是当下岗位最多、最务实的方向。

::: tip roadmap.sh AI Engineer（可视化路线图）
- **权威度**：⭐⭐⭐⭐⭐　**语言**：英文　**免费**：100% 免费
- **适合**：开发者想转入 AI 产品岗、或想看懂招聘 JD 到底要什么。
- **亮点**：社区维护（GitHub 35 万+ stars），可点击的节点地图：从模型 API / 提示词 → 向量库 / RAG → Agent / 工具调用 → 评测 / 安全 / 成本 → 生产部署。它**清晰区分了"AI 工程师（在现成模型上做产品）"和"ML 研究员（从头训模型）"**——很多人白学几个月就是没搞清这条线。
- **延伸**：同站还有 [AI Data Scientist](https://roadmap.sh/ai-data-scientist)（建模/研究侧）和 [AI Agents](https://roadmap.sh/ai-agents)（智能体方向）两张图。

## 六、新手推荐：8 周上手路径（综合多家指南）

下面是一个把上面资源"串成线"的务实方案，每天 30–45 分钟也能走完：

- **第 1–2 周｜概念启蒙**：Elements of AI 或 Google AI Essentials（建立世界观）+ 李宏毅入门视频（中文热身）。目标：能说清"AI / 机器学习 / 深度学习"的区别。
- **第 3–4 周｜动手打基础**：李沐《动手学深度学习》或 Andrew Ng 机器学习专项（跑通第一个模型，改代码看效果）。
- **第 5–6 周｜理解原理**：3Blue1Brown 神经网络系列 + Karpathy《Zero to Hero》（从零手写 GPT，搞懂注意力机制）。
- **第 7–8 周｜做项目**：Hugging Face 课程 + 动手做一个小项目（如"基于自己笔记的 RAG 问答"或聊天机器人），部署到 Hugging Face Spaces。目标：有一个能展示的作品。

> 之后就进入"边做边学"的正循环：选定一个方向（NLP / 视觉 / Agent / 具身智能）深入，跟随前沿论文和新闻。

## 避坑指南（血泪经验）

::: warning 1. 别花钱报 Bootcamp
主流教学内容已经全部免费（上面列的就是）。真要证书，Coursera 的助学金基本都批。
:::

::: warning 2. 别"只看不写"
看视频时**暂停→自己敲一遍代码**。看不是学，写才是学。遇到报错先自己 debug，再查答案。
:::

::: warning 3. 别只背 API
API 半年一变，原理十年不变。学"为什么这样设计"比记"这个函数怎么调"重要十倍。
:::

::: warning 4. 证书不如作品集
面试官更想看你的 GitHub 原创项目，而不是一摞结课证书。用"输出物"代替"看完"。
:::
