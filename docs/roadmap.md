# AI 学习路线总览

> 这是我的个人 AI 进阶路线图。目标不是"看完所有论文"，而是建立一套能持续更新的知识框架：知道每个方向在解决什么问题、主流方案是什么、我该往哪深入。

下面按阶段划分。每个阶段都标注了**目标**、**核心内容**和**验收标准**（你可以把验收标准换成自己的）。

## 阶段一：夯实基础

**目标**：能独立看懂一篇 Transformer / 训练相关的技术文章，不被数学符号劝退。

- 数学：线性代数（矩阵乘法、特征值）、概率统计、微积分基础（梯度、链式法则）
- Python：熟练使用 numpy / pandas，能写清晰的数据处理脚本
- 机器学习基础：监督/非监督学习、损失函数、梯度下降、过拟合与正则化
- 深度学习基础：神经网络、反向传播、CNN/RNN 直觉

**验收**：能用手写笔记推导"单层感知机怎么用梯度下降更新权重"。

## 阶段二：深入 Transformer 与 LLM 原理

**目标**：理解大模型"为什么这样设计"，能讲清注意力机制、位置编码、MoE 等核心概念。

- Transformer 架构：Self-Attention、MHA/GQA/MLA、FFN、残差与归一化
- 位置编码：绝对位置 → RoPE → 长上下文外推
- 训练范式：预训练目标（CLM）、Scaling Law
- 主流架构对比：Dense vs MoE、滑动窗口注意力、线性注意力/SSM
- Tokenizer 与词表：BPE、分词对效果的影响

**验收**：能画出自顶向下的 LLM 架构图，并解释"KV 缓存为什么会随上下文变长而爆炸"。

> 参考笔记：[基础模型 / Claude](/base-models/claude)

## 阶段三：后训练与对齐

**目标**：理解"预训练给知识，后训练给能力"，掌握让模型会思考、听话的关键技术。

- SFT（监督微调）：数据构造、全量微调 vs 参数高效（LoRA / QLoRA）
- 偏好对齐：RLHF（PPO）、DPO、Reward Model
- 推理模型：RLVR（可验证奖励）、思维链（CoT）、"顿悟时刻"
- 推理努力控制：effort mode、token budget、推理时缩放

**验收**：能讲清楚"SFT、RLHF、DPO 分别解决了什么、彼此关系是什么"。

## 阶段四：推理模型与 Agent

**目标**：从"会聊天的模型"走向"能干活的系统"。

- 推理缩放：self-consistency、延长思维链
- 工具调用（Function Calling / Tool Use）：协议、并行调用、错误处理
- Agent 框架：ReAct、规划-执行、记忆与上下文管理
- Deep Research 类系统：检索、多步推理、引用溯源

**验收**：能基于一个开源框架跑通一个"能查资料并给出带引用结论"的最小 Agent。

## 阶段五：工程落地与部署

**目标**：让 AI 能力稳定、低成本地跑在真实业务里。

- 推理优化：量化（INT8/FP8）、KV 缓存管理、批处理、投机解码
- 服务化：vLLM / Ollama / TGI，吞吐与延迟权衡
- 评测：基准测试、人工评估、线上 AB
- 成本控制：模型选型、缓存、路由（小模型兜底 + 大模型攻坚）

**验收**：把一个模型部署成可对外服务的 API，并给出一份成本与延迟的实测报告。

---

## 怎么用这个路线图

1. 不用严格按顺序，允许在阶段间跳（比如先玩 Agent 再补原理）。
2. 每个阶段用"输出物"代替"看完"，比如写一篇笔记、跑通一个 demo。
3. 笔记统一放进 `docs/` 对应目录，侧边栏会自动长出目录树。
